# Table Cards v2 — UX and Accessibility Audit

<!-- markdownlint-disable MD013 -->

Date: 2026-08-18  
Standard: WCAG 2.1 AA plus a 44×44 px mobile target convention  
Scope: study modal, canvas editor, Fields, Block, Reorder, Card style, long content, empty values, and images

## Outcome

No open critical or major findings remain in the tested static production-class fixtures. The editor keeps the canvas as the primary surface, exposes only the current context, and moves detail into one responsive sheet. The study view shows every enabled block immediately and keeps navigation fixed.

## Findings resolved

| Finding | Severity | Resolution |
| --- | --- | --- |
| Empty-value controls appeared twice in the block inspector | Major | Kept them once inside the collapsed **Empty values** group |
| Essential and advanced block controls formed one long panel | Major | Kept type, columns, and move at the top; grouped content, layout, text, appearance, rules, and image options |
| Mobile sheet header could overlap its scrolling body | Critical | Split the bottom sheet into handle, header, independently scrolling body, and footer grid rows |
| Expanded labels collided at 320 px | Major | Used flexible outer columns and compact multiline labels with no horizontal overflow |
| Several controls were 36–42 px on a narrow fine-pointer viewport | Major | Raised editor, sheet, picker, listbox, table, range, and navigation targets to at least 44 px |
| Preview ignored disabled border/shadow | Major | Added preview-specific border and shadow states so the canvas matches the saved card |
| Drag handle had an invalid `op` declaration and resize listeners accumulated | Major | Corrected positioning and added deterministic pointer cleanup plus Escape cancellation |
| Styled listbox search lost focus after the first typed character | Major | Kept typing in the search field and normalized roving option focus |
| Escape from a listbox could close the whole sheet | Major | Escape first closes the listbox and restores its trigger; a second Escape closes the sheet |
| Closing a sheet could lose focus after the editor rerendered | Major | Restored focus to the matching Fields, Block, Reorder, or Card style opener |
| Overlapping file and folder sources duplicated the same table | Major | Deduplicated by source path, header signature, and occurrence, covered by a regression test |
| Root preview still opened the old reveal concept | Moderate | Redirected `preview/index.html` to the all-visible v2 fixture and removed runtime reveal/front/back copy |
| The main deck picker still opened an operating-system menu | Moderate | Replaced it with the same styled, labelled keyboard listbox used by the editor |
| Saving a renamed deck left the open settings page bound to stale data | Major | Added inline naming and refreshed settings from the persisted deck after a successful save |

## Accessibility checks

- Meaningful images have alt text; decorative marks and pointer handles are hidden from assistive technology.
- Sheets expose `role="dialog"`, `aria-modal`, a labelled heading, focus trapping, Escape, and opener focus restoration.
- Custom listboxes expose labelled triggers, expanded state, listbox/option roles, selected state, arrow/Home/End navigation, and type-ahead.
- Text, number, range, color, checkbox, and source controls have programmatic labels.
- Color controls show a live contrast ratio and AA/AAA result before save.
- Reduced-motion mode reduces sheet, preview, and progress animation to effectively zero.
- At 200% equivalent viewport size, the modal and sheet retain independent scrolling with no horizontal document overflow.

| 390×844 | Full-screen editor/study view; bottom sheet has no header/body overlap; all study controls are at least 44×44 px |
| 320×568 | Expanded labels do not collide; block footer uses two compact 44 px actions; reorder rows and long/image cards have no horizontal overflow |

## Verification boundary

Playwright covered screenshots, accessibility snapshots, focus order, keyboard Escape behavior, reduced motion, geometry, overflow, and target size. A final physical-device smoke test of VoiceOver speech, swipe feel, and pinch zoom remains a release-device check because those hardware interactions are outside the browser fixture.
