# Table Cards

<!-- markdownlint-disable MD013 -->

Плагин превращает Markdown-таблицы в сфокусированные карточки внутри Obsidian. Table Cards работает локально, не изменяет исходные заметки и использует один аккуратный чёрно-белый интерфейс на пк и телефоне.

![Мастер настройки рекомендует раскладку словаря по реальным данным таблицы](docs/screenshots/setup-presets-desktop.png)

## Возможности

- Одна колода может включать заметки, папки и любой набор отдельных таблиц.
- Каждая сессия начинается с обязательного лаунчера: до старта видны колода, таблицы и точное число валидных карточек.
- Все включённые блоки карточки видны сразу — лица, оборота и раскрытия нет.
- Поиск проверяет каждую ячейку активных таблиц и открывает точную карточку с контекстом исходной строки.
- Визуальный редактор работает через черновик и показывает отдельные превью пк и телефона.
- Нет телеметрии, перевода во время работы или собственного сетевого клиента.

## Установка

Скопируй три артефакта релиза в `.obsidian/plugins/table-cards/` внутри vault:

```text
main.js
manifest.json
styles.css
```

Затем включи **Table Cards** в **Настройки → Сторонние плагины**. Пользовательские настройки лежат отдельно в `data.json`; deploy-скрипт копирует только три runtime-файла выше.

## Первый запуск

На чистой установке открывается мастер из трёх шагов:

1. **Данные** — добавь одну или несколько Markdown-заметок либо папок и выбери все таблицы или точный набор.
2. **Шаблон** — сравни шесть раскладок на реальной строке. Правила рекомендуют один вариант из **Словарь**, **Фразы**, **Вопрос и ответ**, **Галерея**, **Справочник** и **Универсальный**.
3. **Готово** — назови колоду, выбери иконку и реши, нужна ли отдельная кнопка в левой ленте Obsidian.

Каждый шаблон создаёт обычные редактируемые блоки, а не отдельный режим рендера. Чтобы запустить мастер снова, вызови **Создать колоду с настройкой** через палитру команд или ту же кнопку в **Настройки → Table Cards**. Существующие колоды не заменяются.

## Запуск обучения

Команда **Открыть карточки** показывает общий лаунчер. Выбери колоду, проверь сохранённый набор таблиц и подтверди **Открыть N карточек**. Если очистить выбор, старт станет недоступен.

Кнопка конкретной колоды в левой ленте открывает тот же лаунчер с зафиксированной колодой. Она всё равно требует выбрать таблицы и подтвердить запуск.

![Обязательный лаунчер показывает колоду, таблицы, предупреждения и точное число карточек](docs/screenshots/launcher-desktop.png)

Во время обучения:

- листай кнопками, стрелками `←`/`→` или горизонтальным свайпом;
- клавиша `S` включает перемешивание;
- чип таблиц меняет scope без повторного чтения vault;
- браузер карточек ищет по всем ячейкам активных таблиц;
- результат открывает точную карточку с файлом, названием таблицы и номером строки;
- изображение с включённым zoom открывается по тапу.

Строка источника под карточкой остаётся вторичной и показывает понятный заголовок таблицы и имя файла.

## Визуальный редактор

Открой **Настройки → Table Cards → Раскладка**.

- **Источники** — добавляй заметки и папки, смотри компактный summary и открывай сфокусированный выбор таблиц с поиском, all/none, превью строки и **Открыть эту таблицу**.
- **Поля** — проверяй типы, заполненность, примеры и предупреждения; ручной тип хранится в колоде.
- **Холст** — выбирай блок прямо на карточке. На пк доступен drag, на телефоне и с клавиатуры — явные действия перемещения.
- **Блок** — настраивай столбцы, вид, подпись, ширину, плотность телефона, высоту, overflow, пустые значения, изображения, цвета, рамку и выравнивание.
- **Стиль карточки** — выбирай Obsidian, ч/б или свои цвета и меняй ритм, масштаб текста, скругление, рамку, тень и максимальную ширину.

Источники, авто-раскладка и оформление остаются единым локальным черновиком до кнопки **Сохранить**. Внутри работают undo/redo и `Cmd/Ctrl+Z`, а `Cmd/Ctrl+S` сохраняет. При закрытии грязного редактора можно сохранить, не сохранять или продолжить.

![Редактор оставляет карточку видимой, а таблицы выбираются в одном боковом sheet](docs/screenshots/editor-tables-desktop.png)

## Данные, пустые ячейки и изображения

Плагин определяет текст, число, дату, да/нет, теги, ссылку, Markdown, изображение и смешанный столбец. Блок может скрыть пустое значение, показать тире или свой текст, сохранить место, взять fallback-столбец либо пропустить строку, если поле обязательное.

Поддерживаются Obsidian-вставки вроде `![[image.png|300x200]]` и обычные Markdown-изображения. Доступны contain/cover, aspect ratio, crop focus, подпись, состояние потерянного файла и zoom по тапу. Локальные файлы находятся через vault. Если внешний URL уже записан в Markdown, он передаётся стандартному элементу изображения; Table Cards не добавляет свой image-сервис или сетевой клиент.

## Телефон, клавиатура и RTL

На телефоне одна колонка карточки, полноэкранные sheets выбора и поиска, footers с safe area и controls минимум 44×44 CSS px. Длинный контент остаётся внутри карточки или своего scroll-блока и не создаёт горизонтальный overflow страницы. `prefers-reduced-motion` убирает переходы.

Интерфейс переведён на английский, русский, украинский, испанский, немецкий, французский, бразильский португальский, итальянский, польский, турецкий, упрощённый и традиционный китайский, японский, корейский, арабский и хинди. Auto-режим следует локали Obsidian, ручной выбор показывает нативные названия языков. Арабский разворачивает только chrome Table Cards; данные пользователя сохраняют `dir="auto"` и естественное направление.

![Арабский chrome остаётся RTL, а английский контент карточки сохраняет своё направление](docs/screenshots/study-rtl-mobile.png)

## Миграция и приватность

Настройки схем v1 и v2 идемпотентно переходят на схему v3. Сохраняются ID колод, источники файлов и папок, выбранная таблица, порядок и видимость блоков, override оформления, прогресс, seed перемешивания, локаль и последняя активная колода. Старых пользователей мастер первого запуска не прерывает.

Table Cards никогда не переписывает Markdown-таблицы и не добавляет скрытые ID строк. Карточки и source identity вычисляются в памяти из содержимого vault. Телеметрии, cloud sync, runtime-перевода и удалённой обработки контента нет.

## Намеренные ограничения

- Нет внешней deep link на строку Markdown: у строк нет стабильного нативного ID.
- Нет интервального повторения, оценок и статистики.
- Нельзя менять Markdown-ячейки прямо из карточки.
- Браузер монтирует максимум 100 результатов, но показывает полное число совпадений.

## Архитектура и разработка

Плагин написан на TypeScript и разделён на небольшие модули: scanner/catalog таблиц, scope/search state, пресеты setup, typed i18n-каталоги, координация launcher/study и editor routes. Английский каталог — canonical contract; тест проверяет точное совпадение ключей всех 16 языков. Runtime использует только public API Obsidian и не импортирует Node или Electron.

```bash
npm install
npm test
npm run test:tools
npm run lint
npx tsc --noEmit
npm run typecheck:tools
npm run build
npx playwright install chromium
npm run test:ui
npm run check:links
```

`npx playwright install chromium` — одноразовая установка браузера для чистого checkout. Детерминированные production-class fixtures: `preview/launcher.html`, `preview/setup.html`, `preview/v2.html` и `preview/editor.html`. Playwright проверяет пк, планшет, zoom-equivalent, телефон, арабский RTL, reduced motion, восстановление фокуса, размеры controls, overflow и console output.

Смотри [changelog](CHANGELOG.md) и [UX/accessibility audit](docs/ux-audit-2026-08-18.md). Версия `0.1.0` — первый полный релиз и уже использует product-модель schema v3; номер схемы и версия пакета намеренно независимы.
